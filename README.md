# 电商工具 Go 正式版

用 Go + Wails v2 + Excelize 重构的电商工具，替代 Python/tkinter 版。已正式发布。

## 优势
- 单文件 EXE 更小 (约 13.7MB vs Python 19MB)
- 原生编译，更少杀软误报
- Excelize 直接兼容快麦等导出的 xlsx (Python openpyxl 报 Fill 错误)
- 现代 Web 前端界面 (HTML/JS 暗色主题)

## 功能

### ① 表格核对
- 源表/目标表选择、检索键列设置
- 回填映射 (源列 → 目标列, 可多条)
- 多规格标记 (≥2 种商品 → 备注"多规格")
- 已有数据不覆盖
- 结果另存 `_结果.xlsx` (源文件不改)

### ② 发票处理
- 固定内容区: 从 fixed_config.json 读取(工具不内置), 支持保存
  - 发票类型/含税/项目名称/税收编码/单位/税率 全字段多选项
  - 选项编辑: "税率=0.01,0.03 单位=个,套" 应用到行级下拉
- 发票录入表格: 每行一张发票
  - 发票类型/含税/项目名称/单位/税率/自然人 行级下拉选择
  - 名称/税号/数量/金额/备注 输入 (税收编码用固定内容, 批量一致)
  - 列序: # 发票类型 含税 项目名称 自然人 购买方名称 税号 单位 数量 金额 税率 备注
- **全局粘贴**: 发票页激活时任意位置 Ctrl+V
  - 从第一行填充, 超出才新增; 单列数字→金额/数量/备注; 多列自动映射
  - 符号清洗: 去 ¥￥$ 空格 千分位逗号 引号; 税号仅保留数字英文
- **导入明细**: Excel/CSV 自动匹配列(购方名称/税号/金额/数量/备注/抬头类型)
  - 发票类型映射: 电子普通→普通, 电子专用/专用→专票
  - 自然人自动: 抬头类型=个人 → 是
- **本地模板自动识别**: 文件名含"批量开票-导入开票模板"自动设为模板
- 删除列: 下拉选列 → 清空该列所有行
- **生成发票文档**: 保留模板 11 sheet、流水号自动、行级覆盖

### ③ 图片转JPG
- 批量转换 webp/png/jpg/bmp/gif/tiff/jfif → JPG
- 保留目录树, 非图片文件自动复制
- 透明PNG白底合成, 质量可调(1-100)

### ④ 邮箱发送
- QQ/163 预设, SMTP 465/587 (SSL/STARTTLS)
- 附件支持(Base64 MIME), 配置存本地

### ⑤ 外观设置
- 图片API背景: 下载图片(如 dmoe.cc)设为应用背景, 本地持久化, 重启恢复
- 毛玻璃效果: 模糊度滑块(0-20px) + 卡片透明度滑块(10-90%), 实时预览
- 纯色背景(无图时), 恢复默认

## 结构
```
main.go          Wails 入口
app.go           App 绑定(暴露给前端的方法)
backend/
  match.go       表格核对核心逻辑 (Excelize)
  invoice.go     开票生成核心逻辑 (Excelize)
frontend/        HTML/JS 前端界面
CHANGELOG.md     版本修改日志
.github/workflows/build-wails.yml  Windows EXE 构建 (tag w* 触发)
```

## 本地开发
```bash
# 后端逻辑测试(无需GUI)
go run ./test <源表> <目标表> <源键> <目标键> [映射 源:目标...]

# 开票生成测试
go run ./invtest <模板路径> [输出路径]

# Wails 全量构建
wails build
```
